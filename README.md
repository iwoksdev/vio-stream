# VIO 2 — سینمای شخصی، به سبک تو

رابط سینمایی فارسی و RTL با **iOS Dark**: مشکی خالص، خاکستری خنثی و آبی سیستم، فونت محلی Vazirmatn، پوسترهای واقعی، انیمیشن نرم و نسخهٔ موبایل. حالا با پلیر Video.js، حساب و ذخیرهٔ واقعی روی سرور، اتصال کتابخانهٔ Jellyfin و مرکز دانلود aria2.

> سورس و تنظیمات برای VPS خودتان آماده شده‌اند؛ استقرار خارجی انجام نشده است. پروژه لینک جعلی استریم، حساب نمایشی یا پیشرفت دانلود ساختگی نمایش نمی‌دهد.

## انتشار روی Render

راهنما و وضعیت واقعی در **[RENDER-DEPLOY.md](RENDER-DEPLOY.md)** هستند. پیکربندی پیش‌فرض `render.yaml` رایگان و **بدون ذخیرهٔ پایدار** است؛ حساب‌ها و دانلودها با restart/redeploy ممکن است از بین بروند. گزینهٔ پولی و دارای دیسک در `render.persistent.yaml` جدا نگهداری می‌شود و نیاز به تأیید بودجه دارد. درخواست ساخت هر دو پلن فعلاً به دلیل نداشتن اطلاعات پرداخت مورد پذیرش Render با HTTP 402 رد شده است؛ مخزن آماده است، اما سایت هنوز روی Render منتشر نشده است.

## اجرای توسعه

Node.js **24 LTS پیشنهادی**؛ حداقل 20.19 برای این سورس و وابستگی‌ها. ماژول SQLite native است؛ اگر prebuild پلتفرم شما موجود نبود، Python 3، make و g++ لازم‌اند.

```bash
npm ci
npm run dev
```

Express و Vite روی همان `http://localhost:5173` اجرا می‌شوند و سرور به `0.0.0.0` متصل است. مرورگر فقط URLهای نسبی `/api/...` را فراخوانی می‌کند. از `npm run preview` به‌جای سرور کامل استفاده نکنید؛ preview استاتیک Vite بک‌اند حساب/دانلود ندارد.

تنظیمات اختیاری:

```bash
cp .env.example .env
# مقادیر واقعی خودتان را در .env وارد کنید.
```

`.env` در شروع Node بارگذاری می‌شود؛ تغییر تنظیمات سرویس‌ها نیاز به restart سرور دارد. `.env`، SQLite، فایل‌های دانلود و کلیدها نباید وارد Git یا سورس عمومی شوند. مسیرهای حساس حتی در سرور توسعه از HTTP مستقیم مسدود شده‌اند.

## مرحله‌های پیاده‌شده

### ۱. پلیر حرفه‌ای

- **Video.js 10.0.1 برای React**، پوستهٔ Neutral هماهنگ با آبی iOS، رابط کنترل فارسی.
- MP4/WebM بومی و HLS با آداپتور hls.js؛ دریافت کد پلیر و سپس موتور HLS به‌صورت lazy، فقط هنگام نیاز.
- سرعت واقعی پخش، seek، صدا، زیرنویس WebVTT، تمام‌صفحه، PiP در مرورگر سازگار و میانبر صفحه‌کلید.
- انتخاب کیفیت فقط وقتی منبع HLS و موتور/مرورگر کیفیت‌های واقعی را ارائه کنند؛ برای MP4 تک‌کیفیت، منوی کیفیت جعلی نیست.
- ذخیرهٔ نقطهٔ پخش هر حدود ۵ ثانیه و هنگام توقف/بستن؛ بازگشت به زمان قبلی.
- اصلاح race رخداد metadata در lazy/Suspense با اتصال مستقیم رخدادهای رسانه و بررسی readyState.
- لینک شخصی HTTPS MP4/M3U8 و VTT اختیاری در جزئیات فیلم؛ این منابع شخصی روی همان دستگاه نگهداری می‌شوند.

### ۲. حساب و فهرست شخصی

- ثبت‌نام، ورود، خروج و بازیابی نشست واقعی با SQLite.
- scrypt دارای salt تصادفی (`N=32768, r=8, p=3`)؛ رمز خام ذخیره نمی‌شود.
- token تصادفی ۲۵۶بیتی با digest در دیتابیس، کوکی HttpOnly، SameSite=Strict و Secure در production؛ عمر نشست ۷ روز.
- کنترل Origin برای درخواست‌های تغییردهنده و محدودیت درخواست‌های auth.
- فهرست تماشا و پیشرفت پخش مجزا برای هر کاربر، قابل بازیابی روی دستگاه دیگر.
- تجربهٔ مهمان همچنان localStorage است؛ فهرست مهمان بدون رضایت وارد حساب نمی‌شود. در فرم ورود گزینهٔ انتقال آن وجود دارد.
- دادهٔ قبلی UI هنگام تغییر حساب به کاربر بعدی نشان داده نمی‌شود؛ سابقهٔ محلی پخش هم با شناسهٔ حساب namespace می‌شود.
- ابزار CLI برای ساخت حساب و reset رمز همراه با ابطال نشست‌ها؛ ارسال ایمیل/OAuth/صورتحساب وجود ندارد.

### ۳. کتابخانهٔ Jellyfin

- مرور و جست‌وجوی فیلم و قسمت‌های سریال، صفحه‌بندی، اطلاعات و تصاویر از API واقعی Jellyfin.
- پخش مستقیم فرمت سازگار، یا HLS ترنسکد بر اساس قابلیت فایل و سرور.
- تصاویر، ویدیو، VTT، playlistها، segmentها و URI کلید HLS پشت مسیرهای هم‌مبدأ؛ API key در مرورگر قرار نمی‌گیرد.
- URLهای پخش موقت، محدود به صاحب نشست؛ کش منابع و انقضای ۶ ساعته.
- کتابخانه در این نسخه بین کاربران مجاز VIO مشترک است؛ `JELLYFIN_USER_ID` اختیاری دامنهٔ دید حساب مرجع Jellyfin را مشخص می‌کند.
- اگر سرویس/کلید تنظیم نشده یا پاسخ ندهد، وضعیت روشن است؛ بدون عنوان یا اتصال نمایشی.

### ۴. مرکز دانلود aria2

- صف واقعی روی سرور، وضعیت/حجم/سرعت از JSON-RPC واقعی موتور.
- ورود و تأیید حق استفاده، پیش از ایجاد job؛ دانلود خودکار فیلم‌های کاتالوگ انجام نمی‌شود.
- توقف، ادامه، حذف از فهرست، دریافت فایل و پخش فایل کامل‌شده در فرمت سازگار.
- پشتیبانی از HTTPS دامنه‌های مجاز و magnet با hash معتبر؛ tracker ورودی دلخواه حذف می‌شود.
- دنبال‌کردن gid دانلود اصلی بعد از metadata مگنت، snapshot در SQLite و حفظ اطلاعات فایل کامل حتی پس از پاک‌شدن result history موتور.
- هر job در پوشهٔ مستقل حساب/job قرار می‌گیرد؛ فایل هم‌نام حساب یا دانلود دیگر، دوباره استفاده/بازنویسی نمی‌شود.
- فایل‌ها از طریق endpoint احرازشده، با بررسی مالکیت و محدودبودن مسیر به پوشهٔ دانلود، و پشتیبانی از HTTP Range ارائه می‌شوند.
- «حذف» فایل دیسک را پاک نمی‌کند؛ فقط job/ردیف را حذف می‌کند.

### ۵. Docker / VPS

- Dockerfile چندمرحله‌ای Node 24، Compose، موتور aria2 خصوصی و profile اختیاری Jellyfin.
- Volume پایدار و مجزا برای SQLite، دانلود، جلسهٔ aria2 و تنظیمات رسانه.
- app و aria2 غیر-root، root filesystem فقط‌خواندنی، حذف capabilityها و no-new-privileges.
- Caddy با HTTPS، فشرده‌سازی و هدرهای امنیتی؛ RPC از میزبان منتشر نمی‌شود.
- اسکریپت تولید secret و راهنمای نصب، نگهداری، بکاپ و عیب‌یابی در **[DEPLOY.md](DEPLOY.md)**.

```bash
npm run setup:docker
docker compose --env-file .env.docker up -d --build
# پس از تنظیم دامنه:
docker compose --env-file .env.docker --profile https up -d --build
```

Docker daemon در sandbox توسعه وجود نداشت: پیکربندی و تگ‌های تصاویر بررسی شدند، اما build/run کانتینرها آزمایش عملی نشده است. نسخهٔ Node و aria2 واقعی به‌طور مستقل اجرا و آزمایش شده‌اند.

| [Jellyfin](https://github.com/jellyfin/jellyfin) | سرور رسانهٔ اختیاری و آداپتور REST اختصاصی | GPL-2.0 برای خود سرور |

این پروژه کلون قالب یا مخزن واحد نیست؛ از اجزای واقعی و مستقل استفاده می‌کند. SDK Jellyfin یا WebTorrent به‌عنوان وابستگی نصب نشده‌اند. ارتباط HTTP با سرویس‌های GPL به معنی ادغام کد آن‌ها در فرانت‌اند نیست. متن مجوزها/noticeها در `licenses/` و توضیح اجزا در `THIRD-PARTY-NOTICES.md` است.

- ۱۵ فیلم منتخب کش‌شده با تصاویر و فونت محلی، ۶ کارت خانه، بارگذاری بیشتر.
- جست‌وجوی فارسی/انگلیسی/IMDb و آرشیو زندهٔ YTS.
- فیلتر ترکیبی ژانر، سال، امتیاز و کیفیت، مرتب‌سازی و کالکشن‌های موضوعی.
- دانلود torrent/magnet از hashهای معتبر YTS، کپی، حجم و کیفیت واقعی.
- مودال دسترس‌پذیر، focus trap، Escape، تب‌های صفحه‌کلیدی، deep link فیلم و نسخهٔ موبایل.
- فهرست مهمان، ادامهٔ تماشا و ذخیرهٔ منابع شخصی.

رنگ‌های پایه در `src/styles.css` با `--ios-*` تعریف شده‌اند؛ رابط جدید در `src/platform.css` همان توکن‌ها را مصرف می‌کند. طراحی الهام‌گرفته از iOS است، نه محصول رسمی اپل.

## دانلود ≠ استریم مستقیم

**YTS لینک تورنت می‌دهد، نه MP4/HLS مستقیم فیلم.** API پایه به‌صورت پیش‌فرض `https://movies-api.accel.li/api/v2/` و قابل‌تنظیم است؛ ساختار v2 با [مستند API](https://github.com/BrokenEmpire/YTS/blob/master/API.md) سازگار است. کش، timeout و whitelist جست‌وجو وجود دارند.

سه مسیر واقعی پخش:

۱. منبع شخصی HTTPS در تب «پخش آنلاین»؛ برای VTT/HLS خارجی CORS صحیح روی سرور منبع لازم است.
۲. کتابخانهٔ Jellyfin دارای فایل و مجوز مناسب.
۳. فایل کامل‌شدهٔ دانلود روی سرور با codec سازگار مرورگر.

یا منابع مشترک را در `streams.json` تعریف کنید:

```json
{
  "tt1727587": [{
    "url": "/videos/sintel-trailer.mp4",
    "label": "Sintel official trailer · 480p",
    "type": "mp4",
    "license": "© Blender Foundation | CC BY 3.0",
    "textTracks": [{"url": "/captions/sintel.fa.vtt", "language": "fa", "label": "راهنمای نمونه؛ نه ترجمهٔ گفتگو"}]
  }]
}
```

تریلر سینتل **۵۲٫۲ ثانیه** است. عنوان‌های VTT نمونه توضیحی هستند، نه ترجمهٔ دیالوگ. پیش‌نمایش YouTube نیازمند شبکه است.

پخشِ تورنت در حال دریافت، دانلود/ترنسکد خودکار همهٔ فیلم‌ها، DRM و تضمین swarm/codec وجود ندارد. موتور دانلود به‌تنهایی MKV را قابل‌پخش نمی‌کند؛ برای آن از Jellyfin استفاده کنید. برای سرویس عمومی، quota دیسک، سیاست شبکه، پایش امنیتی و کنترل دسترسی پیشرفته لازم‌اند.

## API

| مسیر | کاربرد |
|---|---|
| `GET /api/status` | نسخه و آداپتور کاتالوگ |
| `GET /api/platform/status` | سلامت واقعی player / accounts / Jellyfin / aria2، بدون کلیدها |
| `GET /api/movies`، `GET /api/movies/:id` | آرشیو YTS + fallback |
| `GET /api/streams/:imdb` | منابع مشترک MP4/HLS |
| `POST /api/auth/register`، `/login`، `/logout`؛ `GET /api/auth/me` | حساب و نشست |
| `GET/POST /api/account/watchlist`؛ `DELETE /api/account/watchlist/:key` | فهرست خصوصی |
| `GET/POST /api/account/progress` | زمان و هویت آخرین فیلم‌ها |
| `GET /api/library` | جست‌وجو و صفحه‌بندی کتابخانه |
| `GET /api/library/items/:id`، `/playback` | deep link خصوصی، منبع نشست‌محور + VTT |
| `GET /api/library/items/:id/image`؛ `/api/library/media/:ticket` | پراکسی امن رسانه |
| `GET/POST /api/downloads` | صف شخصی / ایجاد job |
| `POST /api/downloads/:gid/pause`، `/resume`، `/remove` | کنترل موتور |
| `GET /api/downloads/:gid/file`، `/media` | فایل کامل احرازشده + Range |

## تست

```bash
npm test
# در حالی که سرور توسعه روی 5173 فعال است:
npx playwright install --with-deps chromium
npm run test:ui
# نیازمند aria2 واقعی با RPC خصوصی؛ هیچ Jellyfin واقعی برای این تست preview تنظیم نشده:
npm run test:platform
# پس از export:html، HTML در iframe با شبکهٔ مسدود تست می‌شود:
npm run test:offline
```

- `tests/api.test.mjs`: ۸ تست کاتالوگ/مگنت/دارایی.
- `tests/platform.test.mjs`: ۲۱ تست حساب، جداسازی داده، CSRF، فایل، Range و قراردادهای Jellyfin/aria2 با fixtureهای صریح؛ این بخش ادعای اتصال به Jellyfin واقعی نیست.
- `scripts/verify-ui.mjs`: ۱۳ بررسی قبلی مرورگر.
- `scripts/verify-platform.mjs`: جریان واقعی UI حساب، watchlist، player، VTT، دانلود رسمی سینتل با aria2، توقف/ادامه/تکمیل، مالکیت، موبایل و logout؛ نتایج در `tests/platform-verification.json`.

این تست دانلود از شبکهٔ واقعی استفاده می‌کند و حساب‌های QA با ایمیل تصادفی می‌سازد. نمونهٔ aria2 برای تست pause/resume باید به‌اندازهٔ کافی کند باشد؛ در محیط توسعه محدودیت موقت 150K استفاده شد. اعتبارسنجی HLS Jellyfin در unitها، قرارداد پروتکل است، نه تست decoding یک ترنسکد واقعی.

## production بدون Docker

```bash
npm run build
# تنظیمات HTTPS / reverse proxy و .env را قبل از انتشار کامل کنید.
npm start
```

Express فایل‌های `dist` و API را روی یک پورت سرو می‌کند. Static hosting تنها، حساب/دانلود/کتابخانه را اجرا نمی‌کند. سرور پروکسی باید Host عمومی را حفظ کند؛ `APP_ORIGIN` هم‌مبدأ HTTPS توصیه می‌شود. برای VPS، راهنمای Docker ساده‌تر و دارای حجم‌های پایدار است.

## پیش‌نمایش تک‌فایلی HTML

```bash
npm run export:html
```

`VIO-preview.html` تصاویر، فونت‌ها، کاتالوگ، کد پلیر، CSS و تریلر/عنوان‌های VTT را داخل خود دارد. خروجی آفلاین مخصوص این کار با همهٔ importها inline ساخته می‌شود؛ build عادی production همچنان lazy است.

در HTML، کاتالوگ از seed خوانده می‌شود و **حساب، کتابخانه و دانلود نیاز به بک‌اند دارند**؛ به‌صورت نمایشی جعل نمی‌شوند. YouTube و منابع خارجی بدون شبکه قابل‌استفاده نیستند. اگر iframe دسترسی storage را مسدود کند، فهرست مهمان فقط تا پایان همان بازدید در حافظه می‌ماند. برای حساب واقعی در preview زنده، در صورت مسدودبودن کوکی شخص ثالث، صفحه را در پنجرهٔ مستقل باز کنید.

## ساختار و حقوق

- `src/`: رابط، پلیر، context حساب/سلامت و صفحات شخصی.
- `server/`: حساب/SQLite و آداپتورهای Jellyfin/aria2.
- `server.mjs`، `api-lib.mjs`: سرور یکپارچه و آداپتور YTS.
- `docker/`، `compose.yaml`، `Dockerfile`: VPS / HTTPS / سرویس‌ها.
- `scripts/`: ابزار کاربر، آماده‌سازی، export و QA.
- `licenses/`، `THIRD-PARTY-NOTICES.md`، `ASSET-CREDITS.md`: مجوز/منبع.

سورس اختصاصی VIO تحت MIT است؛ این مجوز حقوق پوسترها و رسانه‌های دیگران را تغییر نمی‌دهد. پوسترها و تصاویر فیلم‌ها فقط برای نمونهٔ طراحی‌اند؛ برای انتشار عمومی/تجاری مجوز بگیرید یا جایگزین کنید. سینتل با CC BY 3.0 و فونت با OFL همراه‌اند. فقط منابعی را دانلود یا پخش کنید که حق استفاده از آن‌ها را دارید.
